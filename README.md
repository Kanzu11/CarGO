# CarGo — Fleet & Landmark Dispatch

Mobile-first ride-hailing, Bajaj, and local fleet dispatch **PWA for Ethiopia**, built to be wrapped as an Android Trusted Web Activity (TWA) and showcased as a live full-stack portfolio product.

- **`/`** — Mobile-first Rider & Driver app (landmark-first pickup crosshair, quick landmark chips, upfront locked ETB fares across Bajaj / Economy / Minivan / Cargo, Cash / Telebirr / CBE Birr toggle, live 3D follow-cam trip lifecycle, and single-device Driver Mode)
- **`/dispatch`** — Full-viewport (`100vh`) Live Geospatial Fleet Command Center (real-time KPIs, tier filters & search, 3D fleet tracking, live Telemetry Inspector, trip timeline, and dispatch interventions)
- **`/design`** — Flat Swiss/industrial design system gallery

**Stack:** Next.js 16 (App Router) · TypeScript (strict) · Tailwind CSS v4 · MapLibre GL v6 (zero-API-key 3D vector basemaps + DEM terrain) · Zustand · lucide-react · Vitest

## Architecture & Real Backend Swapping

The simulated fleet engine (`lib/fleetSimulator.ts`) runs inside `MockTransport` behind the `FleetTransport` interface (`lib/transport/types.ts`). Every client/server message uses typed JSON envelopes (`ServerMessage` / `ClientMessage` in `types/fleet.ts`).

To switch from the in-browser mock simulator to a live Node.js / FastAPI + Redis GEO WebSocket backend, set a single environment variable:

```bash
NEXT_PUBLIC_FLEET_WS_URL=wss://dispatch.your-domain.et/ws
```

`hooks/useFleetConnection.ts` automatically swaps `MockTransport` for `WebSocketTransport` (`lib/transport/wsTransport.ts`) with exponential backoff reconnection and offline queuing — zero UI or store rewrites required.

## PWA & Android TWA (Bubblewrap)

1. Deploy the app to HTTPS (`npm run build && npm run start`, or Vercel/Node).
2. Manifest is served at `/manifest.webmanifest` (`app/manifest.ts`) with `display: "standalone"`, `orientation: "portrait"`, `theme_color: "#09090B"`, and 192px/512px maskable PNG icons generated by `app/icons/[size]/route.tsx`.
3. Generate the Android wrapper project with Bubblewrap:
   ```bash
   npx @bubblewrap/cli init --manifest https://<your-host>/manifest.webmanifest
   npx @bubblewrap/cli build
   ```
4. Copy your signing key's SHA-256 fingerprint and Android `package_name` into `public/.well-known/assetlinks.json`, then redeploy so Chrome launches CarGo in full-screen TWA mode without a browser address bar.
5. Offline resilience: `components/system/NetworkBanner.tsx` displays a 24px top status strip (`"Reconnecting to CarGo dispatch…"`) on `offline` events without clearing persisted trip state in `localStorage`.
